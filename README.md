## Project Description

A 4-bit FPGA-based calculator capable of performing addition and subtraction on two 4-bit operands. The design was implemented in VHDL using AMD Vivado and verified on the Digilent Nexys A7 FPGA board.

## Features

- Addition
- Subtraction
- Binary to BCD Conversion
- Two-Digit Seven Segment Display
- Carry LED
- Result LEDs

## Development Tools

- VHDL
- AMD Vivado 2025.2
- Digilent Nexys A7 FPGA
- Altium Designer
