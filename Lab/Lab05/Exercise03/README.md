# Exercise 03 – 4-Bit BCD Adder
This exercise demonstrates the implementation of a 4-bit BCD Adder with a seven-segment display on the Digilent Nexys A7 FPGA board.
## Files Included
- BCDto7seg.vhd
- binary_to_bcd.vhd
- clock_divider.vhd
- display_mux.vhd
- calculator.xdc
- calculator_top.bit
## Description
The binary arithmetic result is converted into BCD and displayed on the seven-segment display. The design was implemented in VHDL, synthesized using AMD Vivado, and verified on the Digilent Nexys A7 FPGA board.
