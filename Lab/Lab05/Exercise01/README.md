# Exercise 01 – Vivado Introduction
## Objective
The objective of this exercise was to become familiar with the AMD Vivado ML Design Suite and the Digilent Nexys A7 FPGA development board.
During this exercise, we learned how to:
- Create a new Vivado project
- Select the Nexys A7 FPGA board
- Add VHDL source files
- Add an XDC constraint file
- Perform RTL Analysis
- Run Synthesis
- Run Implementation
- Generate the FPGA bitstream
- Program the FPGA board
## Deliverables
According to the laboratory instructions, no deliverables were required for this exercise.
