# Exercise 02 – 4-Bit Adder/Subtractor
This exercise demonstrates the implementation of a 4-bit Ripple Carry Adder/Subtractor on the Digilent Nexys A7 FPGA board using VHDL.
This implementation was verified on the Digilent Nexys A7 FPGA board and corresponds to the integrated 4-bit Adder/Subtractor implementation.
## Files Included
- half_adder.vhd
- full_adder.vhd
- CR_adder.vhd
- CR_add_sub.vhd
- calculator_top.vhd
- calculator.xdc
- calculator_top.bit
## Description
The design performs addition and subtraction on two 4-bit operands. The operands are entered using switches, while the result is displayed on the onboard LEDs. The implementation was verified on the Digilent Nexys A7 FPGA board using AMD Vivado.
