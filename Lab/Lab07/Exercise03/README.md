# Exercise 03 – Two Digit Decimal Counter

## Objective

The objective of this exercise was to design and implement a two-digit decimal counter (00–99) on the Digilent Nexys A7 FPGA board.

## Description

The design counts from 00 to 99 and displays the current count value on two onboard seven-segment displays.

The counter includes:

- Start/Stop control
- Clear (Reset) input
- Two-digit decimal counting (00–99)
- Multiplexed seven-segment display control

The design was synthesized, implemented, and verified using AMD Vivado ML Edition 2025.2.
