# Exercise 02 – One Digit Decimal Counter

## Objective

The objective of this exercise was to design and implement a decimal counter (0–9) on the Digilent Nexys A7 FPGA board.

## Description

The design counts from 0 to 9 and displays the current count value on one onboard seven-segment display.

The counter supports:

- Start/Stop control
- Clear (Reset) input
- Automatic wrap-around from 9 back to 0

The design was synthesized, implemented, and verified using AMD Vivado ML Edition 2025.2.
